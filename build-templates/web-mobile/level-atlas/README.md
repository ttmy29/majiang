# 麻将关卡图鉴 · 校准难度 (level-atlas)

用**真实麻将牌贴图**渲染每一关，并给出用真实用户通关数据校准后的难度值。
放在 `build-templates/web-mobile/` 下，会随 Cocos web 构建一起进入 `build/` 输出；也可直接双击 `index.html` 打开（file://）。

## 怎么用

直接双击打开 `index.html` 即可。
- 列表：真实牌面预览 + 校准难度徽标 + 槽位压力指标，可按难度档 / 机关 / 配置档筛选与排序。
- 点任意关进入详情：左侧是**麻将机自动演示**（按真实规则自动出牌，可看底部槽位填充、三消、自动补全、峰值槽位计量条），右侧是**校准难度分解**；顶部可切换默认 / 重开档 / 广告档对比同一关三档差异。

## 难度怎么算（用户校准 + 玩法模拟）

当前徽标上的 `difficulty.score` 是**用户数据校准后的通关压力分**：
- 读取 `build-templates/web-mobile/自定义事件.csv`，按 `关卡名称 = level.no` 匹配真实聚合数据。
- `通关率(%)` 会限制到 `0–100`，并换算为失败率；进入人数用于贝叶斯平滑，避免小样本关卡剧烈抖动。
- CSV 覆盖的关卡用真实通关压力 + 轻量模型平滑；未覆盖的关卡用同一模型预测，因此属于**真实数据校准后的预测难度**。
- 原始模拟求解分不会丢弃，会保存为 `simDifficulty`，详情页用于解释槽位压力、遮挡和机关负载。

轻量校准模型使用原模拟分、峰值槽位、平均槽位、入槽次数、牌数、层数、遮挡率、机关数量、可解性等结构指标；**不会使用关卡号**，避免把玩家流失/幸存者效应误当作关卡设计难度。

## 模拟结构分怎么算

引擎 `engine.js` 严格复刻游戏运行时机制（见 `assets/game/script/GameCtrl.ts` 等）：
- **遮挡可点**：仅被更高层、行列差 ≤1（半格）的牌遮挡；同层永不互挡。
- **目标槽**：默认解锁 **2** 个，每个集满 **3** 张三消；目标按 `decoded_config.task[0]` 顺序出队，并对卡在底部槽里的"急需类型"插队（`assignNewTarget`）。
- **底部槽位补全**：目标槽变化后自动把匹配的底部存牌吸入（`collectStoredTargets`）。
- **容量判负**：底部存牌槽满 **6** 判负。
- **链 / 铁锁**：成对点击 / 邻居移除后解锁，均按源码实现。
- `flipData / crossChain / blockNum` 运行时未使用 → 引擎忽略（与游戏一致）。

模拟结构分 = 对每关做**迭代加深求解**，得到"按最优玩法仍被迫同时存放的最小峰值槽位压力"为主因，叠加平均槽位占用、被迫入槽频率、规模、遮挡、机关负载，归一到 **0–100** 连续分。
- 分不出胜负（2 槽 cap5 内无解）→ 标记**需解锁/广告**，归入极难段（这是游戏靠广告解锁第 3/4 槽的真实压力点）。
- 四个难度档（简单/普通/困难/极难）的阈值按全体默认关卡的校准分分布自动划定，保证四档都可用；徽标上的**数字**是校准后的当前难度值。
- 配置自带的 `base_diff` / `hard` 是固定占位（全库恒为 7 / 4），仅作对照展示，不参与计算。

## 重新生成（改了关卡或引擎后）

```bash
cd build-templates/web-mobile/level-atlas
node generate.cjs
```

脚本会：扫描 `assets/config_levels_*/{level_json,level_json2,level_json3}/pure_level*_config.json` → 跑 `engine.js` 算难度与演示动作 → 写 `data/levels.js` → 把 `assets/game/resources/mahjong/*.png` 拷到 `tiles/`。
如果存在 `build-templates/web-mobile/自定义事件.csv`，脚本还会读取真实用户通关数据并重算校准难度。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 查看器（列表 + 详情 + 自动演示），加载 `engine.js` 与 `data/levels.js` |
| `engine.js` | 难度模拟引擎（UMD，Node 与浏览器共用，保证"算分逻辑 = 演示逻辑"） |
| `generate.cjs` | Node 生成脚本（关卡扫描、模拟求解、用户数据校准、写出数据） |
| `data/levels.js` | 生成的数据（`globalThis.MAHJONG_ATLAS`） |
| `tiles/` | 从游戏资源拷贝的真实牌图 |

模拟结构分权重可在 `engine.js` 顶部 `CONFIG` 调整；用户校准参数可在 `generate.cjs` 顶部调整。改后重跑 `generate.cjs`。
